Topologi Jaringan

Topologi adalah bentuk atau pola hubungan antarperangkat dalam sebuah jaringan.

Topologi Bus

Semua perangkat terhubung ke satu jalur utama yang disebut backbone. Data yang dikirim melewati jalur tersebut dan perangkat tujuan memeriksa apakah data tersebut ditujukan kepadanya.


Mekanisme: perangkat → backbone → seluruh jalur → perangkat tujuan.

Topologi Ring

Perangkat tersusun membentuk lingkaran. Setiap perangkat terhubung dengan perangkat berikutnya sehingga data dapat diteruskan sepanjang cincin.


Mekanisme: Node A → Node B → Node C → Node tujuan.

Dual-Ring

Dual-Ring menggunakan dua cincin jaringan. Ring kedua dapat digunakan sebagai jalur alternatif atau redundansi ketika jalur utama mengalami gangguan.


Mekanisme: jalur utama + jalur cadangan.

Star

Semua perangkat terhubung ke perangkat pusat, biasanya switch. Data dikirim menuju switch kemudian diteruskan ke perangkat tujuan.


Mekanisme: PC → Switch → PC tujuan.

Mesh

Perangkat memiliki banyak hubungan langsung dengan perangkat lain. Pada full mesh, setiap node memiliki koneksi langsung dengan semua node.


Mekanisme: tersedia banyak jalur menuju tujuan.

Hybrid

Hybrid menggabungkan dua atau lebih bentuk topologi. Contohnya jaringan Star yang digabungkan dengan jaringan Tree.


Mekanisme: beberapa struktur jaringan bekerja dalam satu sistem.

Tree

Tree memiliki struktur bertingkat seperti pohon. Biasanya terdiri dari backbone utama, cabang distribusi, kemudian perangkat akhir.


Mekanisme: backbone → distribution → access → perangkat.

Cara Memilih Topologi

Tidak ada satu topologi yang selalu cocok untuk semua jaringan. Pemilihan bergantung pada kebutuhan dan kondisi jaringan.

Faktor Pertanyaan Pengaruh
Biaya Berapa anggaran perangkat dan kabel? Menentukan perangkat dan desain jaringan.
Jumlah perangkat Berapa banyak komputer yang terhubung? Menentukan skalabilitas.
Keandalan Apakah jaringan harus tetap aktif ketika terjadi gangguan? Redundansi seperti Mesh atau Dual-Ring dapat dipertimbangkan.
Perawatan Seberapa mudah jaringan harus diperbaiki? Desain sederhana lebih mudah dikelola.
Jarak Seberapa jauh perangkat berada? Mempengaruhi media transmisi dan perangkat jaringan.
Performa Berapa banyak data yang akan ditransmisikan? Mempengaruhi kebutuhan bandwidth.

Jenis Kabel & Media Jaringan

UTP

Unshielded Twisted Pair menggunakan pasangan kabel tembaga yang dipilin untuk mengurangi interferensi.

STP

Shielded Twisted Pair memiliki pelindung tambahan untuk membantu mengurangi gangguan elektromagnetik.

Coaxial

Memiliki konduktor pusat, isolator, shield, dan lapisan pelindung. Banyak digunakan pada sistem tertentu seperti kabel TV.

Fiber Optic

Mengirimkan informasi menggunakan cahaya melalui serat optik. Memiliki bandwidth tinggi dan tahan terhadap interferensi elektromagnetik.

Wireless

Menggunakan gelombang radio untuk mengirimkan data tanpa kabel fisik, contohnya Wi-Fi.

Model OSI 7 Layer

OSI membagi proses komunikasi jaringan menjadi tujuh lapisan.

Layer 7 — Application
Menyediakan layanan jaringan yang berhubungan langsung dengan aplikasi. Contoh: HTTP, FTP, SMTP, DNS.
Layer 6 — Presentation
Mengatur representasi data, encoding, compression dan encryption.
Layer 5 — Session
Mengatur pembentukan, pemeliharaan dan penghentian sesi komunikasi.
Layer 4 — Transport
Mengatur komunikasi end-to-end. Contoh: TCP, UDP, SCTP.
Layer 3 — Network
Mengatur alamat logis dan routing. Contoh: IP.
Layer 2 — Data Link
Mengatur frame, MAC address dan komunikasi pada jaringan lokal.
Layer 1 — Physical
Mengirim bit melalui media fisik seperti kabel atau gelombang radio.

Model TCP/IP 4 Layer

4. Application

HTTP, HTTPS, FTP, SMTP, POP3, SNMP dan protokol aplikasi lainnya.

3. Transport

TCP, UDP dan SCTP menyediakan komunikasi antarproses menggunakan port.

2. Internet

IP dan ICMP bekerja pada lapisan Internet. ARP digunakan untuk pemetaan alamat IP ke alamat MAC pada jaringan lokal.

1. Network Access

Mengatur akses ke media jaringan dan transmisi data melalui teknologi seperti Ethernet dan Wi-Fi.
